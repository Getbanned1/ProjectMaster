# ProjectMaster

**ProjectMaster** — онлайн-платформа для управления проектами, задачами и ресурсами.  
Предназначена для команд и менеджеров, обеспечивающая прозрачность процессов, автоматизацию рутинных задач и удобное взаимодействие участников.

---

## 📋 Описание
Система позволяет:
- Создавать и управлять проектами с иерархической структурой работ (WBS).
- Распределять задачи, отслеживать прогресс и сроки.
- Контролировать бюджет и ресурсы.
- Организовывать коммуникацию через чат, форумы и уведомления.
- Генерировать отчеты в формате JSON.

---

## 🌟 Особенности
### Основные функции:
1. **Управление проектами**:
   - Создание/редактирование проектов.
   - Визуализация WBS (Work Breakdown Structure).
   - Назначение задач с приоритетами и зависимостями.

2. **Управление задачами**:
   - Фильтрация по статусу, исполнителю, срокам.
   - Поиск по ключевым словам.
   - Просмотр деталей задачи (описание, комментарии, вложения).

3. **Управление ресурсами**:
   - Учет и распределение ресурсов (люди, оборудование).
   - Отслеживание загрузки и предупреждение о перегрузке.

4. **Бюджетирование**:
   - Формирование бюджета.
   - Учет расходов и генерация отчетов.

5. **Коммуникация**:
   - Встроенный чат и уведомления.
   - Форум для обсуждений.
   - Комментирование задач и обмен файлами.

6. **Администрирование**:
   - Управление пользователями и ролями.
   - Настройка прав доступа.
   - Анализ статистики.
